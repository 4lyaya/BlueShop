# 🛍️ BlueShop - Premium E-Commerce Experience

![BlueShop Banner](assets/images/banner.png)

A modern, responsive e-commerce platform built with HTML5, CSS3, and JavaScript. BlueShop offers a premium shopping experience with smooth animations and intuitive UI.

## ✨ Features

- 🚀 **Fully Responsive** - Works on all devices
- 🔍 **Product Search** - Find what you need quickly
- 🛒 **Shopping Cart** - Easy checkout process
- ⚡ **Fast Animations** - Using AOS library
- 📱 **Mobile-Friendly** - Touch optimized interface
- 🌈 **Modern Design** - Clean, professional look
